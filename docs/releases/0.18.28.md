# RingMaster Club 0.18.28

Released October 24, 2026. Flutter build 208.

- Added a personal member home with memberships, card access, renewal links, upcoming events, and announcements.
- Kept the member workspace and personal card wallet available for accounts without linked clubs.
- Added a separate club management dashboard with pending work, upcoming renewals, recent activity, and visible roster import.
- Added persistent navigation for both workspaces, with desktop sidebars and mobile navigation.
- Limited management entry points to clubs where the signed-in account has staff access. Staff access does not create a personal membership.
- Used the shared RingMaster navy, club green, gold, and text colors throughout the new views.
- Corrected the mobile workspace return action so it exits management with one tap.
- Included the existing annual billing, Show account import, and Easy2Show award parser source in Git.

## Backend alignment

The release audit confirmed that the account import, report reader, billing checkout, and billing subscription webhook source and dependencies match their deployed Supabase versions. The two October billing migrations are already applied. Publishing this web release does not require replaying those migrations or replacing matching functions.

The obsolete, unapplied September pricing draft is retained as reference material under `docs/superseded/`. Generated artifacts, private roster exports, and local caches are excluded from source control.
