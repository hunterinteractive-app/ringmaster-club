# RingMaster Club 0.18.29

Released October 24, 2026. Flutter build 209.

My clubs previously opened the old club selector outside the member workspace. It now opens a club overview inside the persistent navigation, using the shared navy, green, and gold theme.

Each club shows the account's personal memberships and staff access separately. Membership details, renewal requests, club tools, applications, enabled sanction requests, and authorized management remain available. Accounts without linked clubs can open their personal card wallet. Loading failures remain distinct from an empty club list.

Validation: 29 Flutter tests passed, including My clubs navigation, membership identity, staff-only applications and sanctions, member access, phone layout with large text, and load recovery. No backend changes are required.
