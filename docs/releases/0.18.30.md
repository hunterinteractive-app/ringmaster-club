# RingMaster Club 0.18.30

Released October 24, 2026. Flutter build 210.

Account settings previously opened an older standalone page outside the member workspace. Both the account menu and the new navigation entry now open it inside the persistent workspace, including for accounts without linked clubs.

The page uses the shared navy, green, and gold colors and groups linked accounts, signed-in identity, and policies. Edit and Make primary are visible actions. Status badges and account details wrap on phones with large text. Existing account creation, editing, activation, primary selection, policy links, and sign-out remain available. Account changes refresh the workspace display name. Sign-out returns through the root navigator so the signed-in workspace is removed.

Loading failures remain distinct from an empty account list. Validation: 38 Flutter tests passed, covering navigation, account action targets, active and inactive controls, policies, busy states, phone layout with large text, and load failure recovery. Changed Dart files pass analysis. No backend or database migration is required.
